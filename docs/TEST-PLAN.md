# 论文工作台验收计划

使用合成论文和独立测试目录。单元测试中的语义结果是固定测试数据；模型接入通过 Desktop 实际会话另行验收。每项记录通过、失败或未验证，不以构建通过替代行为验收。

| 编号 | 场景 | 预期 |
|---|---|---|
| P01 | 新建论文、重复名称、多项目切换 | 独立目录与状态 |
| P02 | 导入已有目录、重复导入、空目录 | 正确文件列表；重复目录复用 |
| P03 | 非法路径、无权限目录、目录不存在 | 可读错误且保留当前数据 |
| P04 | 关闭工作台、返回主会话、重新打开 | 文件、评论、PDF、会话可恢复 |
| F01 | 行内创建文件、Enter、Esc | 创建或取消，无弹窗 |
| F02 | 重复文件、中文名、嵌套目录 | 正确创建；重复不覆盖 |
| F03 | 路径越界与符号链接 | 拒绝写入 |
| F04 | 多标签、关闭当前/最后/非当前标签 | 不丢失草稿 |
| F05 | 编辑、保存、快捷键、重新启动 | 保存正确，草稿恢复 |
| F06 | Agent/外部编辑同时修改 | 冲突检测，保留草稿 |
| C01 | 真实编译、PDF、下载 | 页面正确可读 |
| C02 | 语法错误、缺失包/图片/工具 | 错误日志和上次 PDF 保留 |
| C03 | 快速连点、取消、超时 | 单任务，进程回收 |
| C04 | 子目录主文件、多文件引用 | 正确路径与输出 |
| C05 | 编译中修改文件或切换项目 | 提示过期，结果不串项目 |
| R01 | 鼠标/键盘/跨行选择 | 近旁显示润色、缩减、评论 |
| R02 | 评论保存、跳转、标记解决 | 锚点正确，持久化 |
| R03 | 单选、多选、全选、取消全选 | 数量与半选状态一致 |
| R04 | 单条与批量加入原有对话 | 保留原草稿，不自动发送 |
| R05 | 引用文字移动、删除、重复出现 | 唯一匹配或明确失效提示 |
| A01 | 原生模型回复、模型切换 | 复用 Harness 配置 |
| A02 | 原生工具修改论文及审批 | 工作区约束与审批有效 |
| A03 | 主会话返回、聊天收起/打开 | 恢复正确会话与草稿 |
| A04 | 最近会话复用、新会话显式创建 | 不意外创建重复会话 |
| M01 | 模型生成四级语义导图 | 标题、章节、段落、句子 |
| M02 | abstract/section/subsection | 自动归属最近结构 |
| M03 | 单段修改后更新、移动、删除、重复段 | 增量分析正确 |
| M04 | 模型取消、超时、非法 JSON | 不损坏原文 |
| M05 | 公式、注释、宏、列表、参考文献 | 保护原始 LaTeX 语义 |
| M06 | 分支折叠、缩放、定位 | 层级清晰且定位正确 |
| V01 | 浅色、深色、系统主题 | 文字、节点、选择高亮可读 |
| V02 | 宽窄窗口、长文件名、长评论 | 无遮挡或操作失联 |
| V03 | 反复打开关闭与切换 | 无重复监听或残留浮层 |
| S01 | 源码、构建包、截图、GIF 隐私检查 | 无凭据与无关个人内容 |
| S02 | 插件加载、禁用、重启与卸载 | 原生会话保持可用 |
